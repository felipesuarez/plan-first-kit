# Tidewater Pottery Studio: Design brief

## Colours

| Name | Hex | Use |
|---|---|---|
| Tide | #1D4E63 | Headings, logo and links |
| Clay | #C8654B | Main buttons only |
| Shell | #F6F1EA | Page background |
| Charcoal | #25292E | Body text |
| Glaze | #7FB8AD | Highlights and "ready to collect" badges |

## Fonts

Headings in Fraunces. Everything else in Source Sans 3, never smaller than 17px on a phone.

## How things look

| Element | Rule |
|---|---|
| Buttons | Clay, fully rounded, one main button per screen |
| Forms | One question per line, labels above the box, help text below it |
| Logo | Top left on every page, never stretched or recoloured |
| Photos | Real studio photos, warm light, hands and clay. No stock imagery of people |
| Screens | Designed for a phone first, because most members book from one |

## Words on screen

- Friendly and hands-on, like a good instructor: "Book a seat", not "Register for session".
- Short sentences. No jargon.
- Say what happens next: "We'll email you when it's ready."
- Errors never blame the person: "That link has timed out. Here's a new one."
